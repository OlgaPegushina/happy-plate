# HappyPlate — доставка еды, которая радует

HappyPlate — маркетплейс доставки еды, где каждый найдёт блюдо по душе. Мы соединяем сотни ресторанов с вашими желаниями: быстро, удобно и с заботой о деталях.

Техническая сторона — это отказоустойчивая микросервисная платформа: централизованные конфиги, распределённая трассировка и слаженное взаимодействие сервисов, чтобы ваша тарелка приезжала вовремя.
